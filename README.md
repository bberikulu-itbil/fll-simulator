# BIOGLOW робот симуляторы

**FIRST® LEGO® League Challenge 2026–27 BIOGLOW** ойынына дайындалуға арналған **бейресми** симулятор. Браузерде жұмыс істейді.

> **This is a modified version** (2026-11-27) of [andrewjgcoward-dot/fll-bioglow-simulator](https://github.com/andrewjgcoward-dot/fll-bioglow-simulator), itself based on [masterpigg/fll-bioglow-simulator](https://github.com/masterpigg/fll-bioglow-simulator). ## Іске қосу

`index.html` файлын екі рет басып ашуға болмайды: браузер модульдерді `file://` арқылы жүктемейді. Жоба бумасында:

```bash
python -m http.server 8000
```

Сосын <http://localhost:8000> ашыңыз. Windows-та `python` табылмаса, `py -m http.server 8000` жазыңыз.

## Не істей алады

- SPIKE Prime стиліндегі сөздік блоктармен бағдарлама құру, `.llsp3` файлдарын ашу және сақтау (қолдау табатын блоктар ғана).
- 2D карта, 3D алаң (миссиялар қарапайым блок түрінде), 3D робот.
- 2:30 матч, 15 миссияның ұпай парағы, жаттығу тапсырмалары.
- Қазақша, орысша, ағылшынша интерфейс.

## Робот пен физиканы нақты роботқа сәйкестендіру

Бастапқы EV3 роботының өлшемдері **фотодан шамамен** алынған.

1. **Робот** бөлімінде дөңгелек диаметрін, дөңгелектер арасын, корпус өлшемін, датчик пен тетік орнын сызғышпен өлшеп жазыңыз. Фотода түс не қашықтық датчигі көрінбеді: симулятордағы датчиктерді өз роботыңызға сай баптаңыз.
2. Сол бөлімдегі физика мәндерін (масса, ілінісу, мотор моменті, тетік массасы) түзетіңіз. Бастапқы мәндердің **бәрі өлшенбеген болжам**.
3. **Баптау** бөлімінде кеңестерді қосып, картадағы модельді басыңыз. Нақты модельді сынап, итеру бағытын, ең аз күшті, ең үлкен жылдамдықты қойыңыз. Алдын ала ешбір шек қойылмаған.
4. **Калибрлеу** сынақтарын нақты роботта жүргізіп, нәтижесін енгізіңіз.

### Физиканың шектеулері

- Итеру күші = мотор күші мен дөңгелектің ілінісу күшінің кішісі. Соққы мен инерция есепке алынбайды. Бастапқы мәндерде 50% пен 100% жылдамдықтағы күш бірдей (≈ 4,4 Н), өйткені ілінісу шектейді.
- Айыр бос бөлшектерді ғана көтереді. Ол фотодағы роботта жоқ, қосымша тетік ретінде берілген.
- Миссия модельдерінің иінтіректері мен топсалары модельденбейді.
- Симулятордың нәтижесі нақты алаңдағы нәтижеге кепіл емес.

### EV3 туралы

Фотодағы робот LEGO EV3 сияқты, ал симулятордың блоктары мен файл форматы **SPIKE Prime** үшін жасалған. EV3 бағдарламалары ашылмайды, мұнда жазылған бағдарлама EV3-ке жүктелмейді.

## Жариялау

Кодты өзіңіздің **ашық** GitHub репозиторийіңізге салыңыз. GitHub Pages: **Settings → Pages → Deploy from a branch → main → / (root)**.

Сайтты басқаларға ашсаңыз, AGPL-3.0 талабы бойынша олар **сіздің нұсқаңыздың** бастапқы кодын ала алуы керек. `index.html` ішіндегі мына жолға репозиторий сілтемесін жазыңыз, сонда бет астында «Бастапқы код» сілтемесі шығады:

```html
<meta name="source-url" content="https://github.com/USERNAME/REPO">
```

`LICENSE` файлын және авторлар туралы сілтемелерді өшірмеңіз.

## Әзірлеу

Тесттерге Node 18 не одан жаңасы керек, қосымша пакет орнатылмайды:

```bash
npm test
```

Файл өзгерткен сайын `index.html` ішіндегі `VERSION` мен стиль файлының `?v=` мәнін жаңартыңыз. Жаңа модульді сол жердегі import map тізіміне қосыңыз.

| Файл | Мазмұны |
| --- | --- |
| `src/app.js` | Бет интерфейсі |
| `src/sim.js` | Қозғалыс, датчиктер, соқтығыс, бағдарламаны орындау |
| `src/physics.js` | Итеру және көтеру күші |
| `src/field.js` | Карта өлшемі, модель орындары, ұпай ережелері |
| `src/robot-ev3.js`, `src/robot-viewer.js` | EV3 роботының 3D моделі |
| `src/i18n.js`, `src/lang/` | Аудармалар (әр жол: ағылшынша, қазақша, орысша) |
| `src/blocks.js`, `src/workspace.js` | Блоктар және редактор |

Қосымша: [TRAINING.md](TRAINING.md) (жаттығу режимі), [LOCAL-MODEL-PACKS.md](LOCAL-MODEL-PACKS.md) (өз 3D модельдеріңіз).
